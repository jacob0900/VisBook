Este repositorio contiene un análisis exploratorio de datos (EDA) realizado sobre variables económicas del Banco de la República. El archivo principal EDA.html reúne visualizaciones y resultados que permiten examinar el comportamiento de las variables estudiadas. Los usuarios pueden descargar este archivo directamente desde el repositorio y abrirlo en cualquier navegador web para explorar las gráficas y conclusiones de manera sencilla, sin necesidad de instalar software adicional.
