Este repositorio contiene un análisis exploratorio de datos (EDA) sobre variables macroeconómicas del Banco de la República. El archivo principal EDA.html reúne visualizaciones y resultados que permiten examinar el comportamiento de las variables estudiadas, incluyendo pruebas de estacionariedad aplicadas como parte de la preparación para modelos de predicción. El objetivo es avanzar hacia la implementación de un modelo ARIMA que permita realizar pronósticos sobre variables macroeconómicas, apoyándose en la validación de supuestos y en la exploración inicial de los datos. Para visualizar correctamente el reporte, los usuarios deben descargar el repositorio completo y abrir el archivo EDA.html en cualquier navegador web.
